💅 The Nail Diary — Salon Website
A premium, fully responsive single-page website built for The Nail Diary, a nail salon & beauty studio in Virar West, Maharashtra. Designed with a luxurious gold & black aesthetic, it features smooth scroll navigation, an animated custom cursor, a services showcase, photo gallery, client testimonials, Instagram grid, and a booking form with validation. Built entirely with vanilla HTML, CSS, and JavaScript — no frameworks, no dependencies, no build tools required. All assets including images are embedded directly into a single self-contained HTML file, making it plug-and-play with zero setup. Crafted with attention to detail, responsive across all screen sizes, and optimised for a high-end salon experience.
---
✨ Features
Custom Animated Cursor — ripple splash effect on click
Responsive Navbar — desktop links + mobile hamburger drawer
Hero Section — full-screen with animated nail-drop motif
Services Showcase — interactive cards with hover effects
Photo Gallery — masonry-style grid with overlay animations
Testimonials Slider — auto-scrolling client reviews
Instagram Grid — 6-photo feed linked to salon profile
Booking Form — with client-side validation (name, phone & date required)
Contact Section — phone, address, hours & Google Maps link
WhatsApp Button — floating quick-enquiry button
Fully Responsive — mobile, tablet & desktop
---
